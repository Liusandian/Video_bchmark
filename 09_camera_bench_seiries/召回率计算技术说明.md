# 深度估计相机运动检测召回率计算技术说明

## 概述

本文档详细说明了基于深度估计的相机运动检测系统中召回率计算的实现原理、算法流程和技术细节。召回率计算是评估系统性能的重要指标，特别是在多类别运镜类型检测中具有重要意义。

## 🎯 召回率计算的重要性

### 1. 多类别评估需求
传统的整体准确率无法反映各种运镜类型的检测效果差异：
- **pan_left** 可能召回率很高（90%+）
- **dolly_out** 可能召回率较低（60%）
- **static** 可能存在误判问题

### 2. 深度估计效果评估
需要量化深度估计技术对不同运镜类型的改进效果：
- 哪些运镜类型从深度估计中获益最大
- 哪些运镜类型仍需要算法优化
- 深度估计方法的使用率和成功率

## 🔧 核心算法实现

### 1. 基础数据结构设计

```python
type_stats = defaultdict(lambda: {
    'total': 0,                    # 该类型总样本数
```

```python
# 统计每种运镜类型的结果
for result in video_results:

    gt_type = result['ground_truth']              # 真实标签

    predictions = result.get('predictions', [])   # 预测结果列表
```

**关键设计点**：
- **阈值判断**: `video_results > 0.5` 确定预测是否正确
- **错误记录**: 保存错误预测结果用于后续分析
- **动态统计**: 自动处理新出现的运镜类型

#### 2.2 深度估计使用率检测

```python
# 检查是否使用了深度估计（通过预测结果的复杂度判断）
```

**检测策略**：

### 2. 混淆矩阵生成

```python
def generate_confusion_matrix(video_results):
    """生成运镜类型混淆矩阵"""
    confusion_data = defaultdict(lambda: defaultdict(int))
    
    for result in video_results:
        gt = result['ground_truth']
        predictions = result.get('predictions', ['unknown'])
        
        # 取第一个预测作为主要预测
        pred = predictions[0] if predictions else 'unknown'
        confusion_data[gt][pred] += 1
    
    return confusion_data
```

## 🔢 数学原理

### 1. 召回率计算公式

```
召回率 (Recall) = TP / (TP + FN)

其中：
- TP (True Positive): 正确预测为该类型的样本数
- FN (False Negative): 实际为该类型但预测错误的样本数
```

### 2. 深度方法效果评估

```
深度增强效果 = (使用深度方法的召回率 - 传统方法召回率) / 传统方法召回率

效果分级：
- 高效益: 效果 > 30% AND 绝对召回率 > 80%
- 中等效益: 效果 > 15% AND 绝对召回率 > 60%
- 低效益: 其他情况
```

### 3. 置信区间计算

```python
def calculate_confidence_interval(correct, total, confidence=0.95):
    """计算召回率的置信区间"""
    import scipy.stats as stats
    
    p = correct / total
    z = stats.norm.ppf((1 + confidence) / 2)
    margin = z * np.sqrt(p * (1 - p) / total)
    
    return (max(0, p - margin), min(1, p + margin))
```
